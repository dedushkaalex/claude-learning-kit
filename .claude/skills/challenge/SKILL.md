# Challenge

Read:
- `learning/progress.md`
- `learning/concepts.md`
- `learning/mistakes.md`
- `learning/roadmap.md`
- `learning/session.md`

## Create One Challenge

Choose a concept with mastery 2–4/5.

The challenge must:
- be small enough to finish in one session;
- require actual coding;
- be meaningfully different from the original exercise;
- test reasoning, not memorization;
- use the project's actual stack;
- contain no solution.

Give:
1. context;
2. goal;
3. constraints;
4. acceptance criteria;
5. one optional hint hidden behind a request.

Then STOP.

## Evaluation

After the student finishes:
1. inspect the implementation;
2. run relevant checks;
3. ask the student to explain the key decision;
4. score mastery 0–5;
5. record important misconceptions;
6. decide whether to reinforce or advance.

Do not rewrite the solution.
