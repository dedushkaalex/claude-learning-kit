Как читать тип Effect<A, E, R>

ПозицияВопрос, на который отвечаетПример из проекта
AЧто вернётся при успехеfindTodo: Todo
EКакие ошибки вызывающий код может обработатьfindTodo: TodoNotFound
RКакие сервисы нужны до запускаnewTodo: TodoIdGenerator

Правило чтения ошибки компилятора: первая ошибка в выводе tsc, первые три строки. Если в типе значения стоит =>, функция не вызвана. Если R = unknown, под yield* стоит не эффект.

Три способа собрать эффект

// 1. Генератор: нужны промежуточные значения
export const newTodo = Effect.fn("newTodo")(function* (title: string) {
  const idGenerator = yield* TodoIdGenerator        // R += TodoIdGenerator
  const id = yield* idGenerator.next                // A этого эффекта
  const createdAt = yield* DateTime.nowAsDate       // Clock имеет default, R не растёт
  const validTitle = yield* validateTitle(title)    // E += EmptyTitle | TitleTooLong
  return { id, completed: false, title: validTitle, createdAt }
})

// 2. pipe: каждый шаг видит только предыдущий результат
const validateTitle = (title: string) =>
  Schema.decodeEffect(Title)(title).pipe(
    Effect.mapError(() => title.trim().length === 0 ? new EmptyTitle() : new TitleTooLong({ max: 100 })),
  )

// 3. flatMap: следующий шаг сам возвращает эффект
Effect.flatMap(TodoClient, (client) => client.todos())
ОперацияCallback возвращаетДействует на
Effect.mapобычное значениеA
Effect.flatMapEffectA, E и R складываются
Effect.tapEffect, результат отбрасываетсяничего, побочное действие
Effect.mapErrorобычное значение ошибкиE
Effect.catchTagEffect с заменойубирает один тег из E
Effect.orDie—E становится never
Effect.flip—меняет A и E местами
Effect.provide—убирает Out слоя из R

Schema: одна схема, два типа

export const TodoId = Schema.String.pipe(Schema.brand("TodoId"))
export const Title = Schema.Trim.check(Schema.isNonEmpty(), Schema.isMaxLength(100))
export const Todo = Schema.Struct({
  id: TodoId,
  completed: Schema.Boolean,
  title: Title,
  createdAt: Schema.DateFromString,   // Type = Date, Encoded = string
})
export type Todo = typeof Todo.Type

Сервисы и слои

export class TodoIdGenerator extends Context.Service<
  TodoIdGenerator,
  { readonly next: Effect.Effect<TodoId> }
>()("app/TodoIdGenerator") {
  static readonly layer = Layer.succeed(TodoIdGenerator, {
    next: Effect.sync(() => TodoId.make(crypto.randomUUID())),
  })

  static readonly layerTest = Layer.effect(
    TodoIdGenerator,
    Effect.gen(function* () {
      const counter = yield* Ref.make(0)               // одна ячейка на один экземпляр слоя
      return { next: Ref.getAndUpdate(counter, (x) => x + 1).pipe(Effect.map((n) => TodoId.make(`todo-${n}`))) }
    }),
  )
}

Правило размещения: домен (types.ts, todoRules.ts) не импортирует из сервисов. Конкретный слой подаётся в точке сборки (todoRuntime.ts, main.ts), а не внутри модуля, который им пользуется.

Обобщённый helper для use case

const updateTodos = Effect.fn("updateTodos")(function* <E, R>(
  step: (todos: ReadonlyArray<Todo>) => Effect.Effect<ReadonlyArray<Todo>, E, R>,
) {
  const todoRepository = yield* TodoRepository
  const todos = yield* todoRepository.all
  const next = yield* step(todos)
  yield* todoRepository.save(next)
  return next
})

Без параметров E и R каждый вызывающий получил бы объединение всех ошибок, и catchTag перестал бы сужать тип.

Самопроверка перед словом «готово»

  1. Выполнить pnpm check.
  2. Прочитать первую ошибку из вывода tsc, а не верхнюю в редакторе.
  3. Убрать неиспользуемые импорты (TS6133).
  4. Назвать вслух A, E, R новой функции.
