Точка сборки: один runtime на модуль

export const runtime = Atom.runtime(
  Layer.merge(
    TodoClient.layer.pipe(Layer.provide(FetchHttpClient.layer), Layer.provide(browserConfig)),
    KeyValueStore.layerStorage(() => localStorage),
  ),
)

runtime объявлен на уровне модуля. Внутри компонента он создавался бы на каждый рендер вместе со всеми сервисами и их состоянием.

Источник, ключ, производные

export const todosAtom = runtime
  .atom(Effect.flatMap(TodoClient, (client) => client.todos()))
  .pipe(Atom.withReactivity(["todos"]))                      // источник помечен ключом

export const createTodoAtom = runtime.fn(
  (title: string) => Effect.flatMap(TodoClient, (client) => client.create(title)),
  { reactivityKeys: ["todos"] },                             // после успеха источник перечитывается
)

export const activeCountAtom = Atom.make((get) =>           // зависимость через get, ключ не нужен
  AsyncResult.map(get(optimisticAtom), (todos) => todos.filter((todo) => !todo.completed).length),
)

Что перезапускается после create: todosAtom по ключу, затем optimisticAtom, visibleTodosAtom и activeCountAtom по цепочке get. filterAtom не трогается.

Оптимистичное обновление

export const optimisticAtom = Atom.optimistic(todosAtom)          // записываемая копия источника

export const toggleTodoAtom = Atom.optimisticFn(optimisticAtom, {
  reducer: (current, { id, completed }: ToggleInput) =>            // предварительное значение копии
    AsyncResult.map(current, (todos) =>
      todos.map((todo) => (todo.id === id ? { ...todo, completed } : todo)),
    ),
  fn: runtime.fn(({ id, completed }: ToggleInput) =>               // без reactivityKeys
    Effect.flatMap(TodoClient, (client) => client.toggle(id, completed)),
  ),
})
  1. Запись в toggleTodoAtom кладёт результат reducer в копию с waiting: true.
  2. Выполняется fn.
  3. Успех: источник todosAtom перечитывается, копия принимает его значение.
  4. Ошибка: копия откатывается к последнему значению источника.

Ресурс на время монтирования

export const todosSyncAtom = runtime.atom(
  Effect.acquireRelease(
    Effect.sync(() => { window.addEventListener("storage", onStorage); return onStorage }),
    (handler) => Effect.sync(() => window.removeEventListener("storage", handler)),   // release возвращает эффект
  ),
)
// в компоненте: useAtomMount(todosSyncAtom)

Освобождение выполняется, когда атом теряет последнего подписчика, на одну задачу позже и только если никто не подписался снова. Таймлайн: жизненный цикл атома.

Параллельные запросы из одного действия

export const clearCompletedAtom = runtime.fn<void>()(
  () => Effect.gen(function* () {
    const client = yield* TodoClient
    const todos = yield* client.todos()
    const completed = todos.filter((todo) => todo.completed)
    yield* Effect.forEach(completed, (todo) => client.remove(todo.id), { concurrency: 3, discard: true })
  }),
  { reactivityKeys: ["todos"] },        // обычный runtime.fn: ключ нужен, никто другой источник не обновит
)

Первая ошибка прерывает остальные запросы в полёте, и весь эффект завершается этой ошибкой. Часть удалений при этом уже выполнена на сервере. Альтернатива без частичного отказа: один эндпоинт DELETE /todos?completed=true.
